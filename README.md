# 学习进度

一款基于 Flutter 开发的本地网课学习进度记录工具。

## 功能特性

### 课程管理
- 按课程类型分类管理课程（侧边栏按类型展开）
- 课程可设置总章节数，用于概览进度展示
- 分类概览页支持课程排序（手动拖拽排序）
- 侧边栏点击分类标题进入分类概览页

### 章节管理
- 支持手动排序、按章节序号排序、按添加时间排序
- 学习状态：学习中 / 已完成
- 支持设置学习日期、备注信息

### 概览页面
- 总览页：整体统计、连续学习天数、本周/本月学习图表
- 最近学习记录（显示课程名+类型名）
- 课程进度列表（显示类型标签 + 完成度）
- 本周 / 本月学习数据切换

### 全局搜索
- 搜索课程名、章节标题、备注
- 点击章节搜索结果跳转课程详情并高亮对应章节

### 数据备份与恢复
- 本地备份导出（.bak 格式，本质 JSON）
- WebDAV 云同步备份
- 自动同步开关 + 最近同步时间显示
- 导入前自动清空数据防名称冲突

### 网页管理
- 局域网内启动 Web 服务器
- 同网络下通过浏览器访问即可管理课程和章节
- 界面风格与 APP 一致（MD3 风格 + 分类分组）

### 密码保护
- 可设置 APP 启动密码
- 支持修改 / 取消密码

### 个性化设置
- 主题色、强调色自定义
- 深色 / 浅色 / 跟随系统模式
- 默认启动页：总览 或 上次学习的课程

## 技术栈

- **框架**：Flutter 3.x + Dart 3.x
- **设计**：Material 3 (MD3)
- **状态管理**：Provider
- **本地存储**：SQLite (sqflite)
- **云备份**：WebDAV (http)
- **网页服务**：Dart `dart:io` HttpServer

## 编译

```bash
flutter pub get
flutter build apk --release
```

APK 输出路径：`build/app/outputs/flutter-apk/app-release.apk`
